# PhysioK29 — Storage Documentation

## Buckets

### `class-resources`
- **Public**: No (signed URLs used)
- **Purpose**: Store lecture PDFs, PPTs, documents, images, and other course materials
- **Max file size**: 50 MB (enforced client-side in `uploadResource()`)
- **Access**: Staff only (authenticated via Supabase Auth)

**Path convention**: `{courseCode}/{uuid}-{safeFileName}`

**Policies**:
- SELECT: `authenticated` + `is_staff()`
- INSERT: `authenticated` + `is_staff()`
- DELETE: `authenticated` + `can_delete_resource_object(name)`
- UPDATE: Not explicitly granted (managed via resource operations)

**Usage**:
- Upload: `supabase.storage.from('class-resources').upload(filePath, file)`
- Read: Signed URLs (60 min expiry) generated by Edge Function via `createSignedUrl()`
- Delete: `supabase.storage.from('class-resources').remove([path])` before resource row deletion

### `birthday-photos`
- **Public**: Yes
- **Purpose**: Store student birthday profile photos
- **Max file size**: 10 MB (enforced client-side)
- **Access**: Public read, any authenticated user can upload

**Path convention**: `birthday-photos/{memberId}-{timestamp}.{ext}`

**Policies**:
- SELECT: `public` (anyone can read)
- INSERT: `public` (anyone can upload — rate-limited only by Edge Function)
- UPDATE: `public`

**Usage**:
- Upload: `supabase.storage.from('birthday-photos').upload(filePath, file)`
- Read: Public URLs via `getPublicUrl()`
- Public URL pattern: `https://{ref}.supabase.co/storage/v1/object/public/birthday-photos/{path}`

## File naming conventions
- Resources: `{courseCode}/{uuid}-{sanitized-filename}`
- Birthday photos: `birthday-photos/{memberId}-{timestamp}.{ext}`
- Sanitization removes special characters, keeps `[a-zA-Z0-9._-]`

## Edge Function Integration
- `member-portal` creates signed URLs for resource downloads via `createSignedUrl(bucket, path, 3600)`
- `birthday-notify` does not directly access storage
- Resource uploads go through client-side Supabase SDK, not Edge Functions
